# Illustrated PDF editions

Start with the **95-page illustrated reading guide**. Use the **2,711-page complete engine reference** for every registered unit/structure card and the full mission trigger, team, script and override ledgers.

- [Download the illustrated reading guide](Red-Alert-2-Illustrated-Reading-Guide.pdf) - approximately 19.2 MB.
- [Download the complete engine reference](Red-Alert-2-Complete-Engine-Reference.pdf) - approximately 28.8 MB.
- [Read the illustrated Markdown guide](../../ENGINE-GUIDE/README.md).
- [Image provenance and evidence limits](../../ENGINE-GUIDE/IMAGES.md).

Both PDFs contain a clickable contents section, bookmarks, selectable text, nine existing project screenshots, eight workflow diagrams, and placement schematics for all 41 recovered scenario maps. The complete reference includes all 137 illustrated-guide Markdown documents. The reading edition explicitly selects representative unit/structure workflows; the complete reference preserves all cards.

The screenshots are historical project captures, not new complete playthroughs. The placement schematics are derived from starting-object coordinates and omit terrain, elevation, passability and later reinforcements. Original evidence limits remain in both books.

Blue links target included sections where possible. References omitted from the reading edition open the corresponding GitHub page; use the complete reference when you need the full offline reference. Opening the bookmarks panel and searching by unit, building, mission name or stable ID is easier than scrolling through the large reference.
